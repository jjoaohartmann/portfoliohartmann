## 📖 Sobre o projeto

Este portfólio foi desenvolvido como parte da minha trajetória escolar, com o objetivo de **apresentar meus projetos, habilidades e aprendizados** de forma organizada e profissional.

Mais do que uma vitrine, ele representa a evolução do meu conhecimento em desenvolvimento web, aplicando na prática boas práticas de código, design responsivo e publicação em produção.


🌐 **Projeto online:** [https://portfoliohartmann.vercel.app/](https://portfoliohartmann.vercel.app/)

## ✨ Funcionalidades

- 📱 **Layout responsivo**, adaptado para celular, tablet e desktop
- 🧑‍💻 **Seção "Sobre mim"** com apresentação pessoal e formação
- 🗂️ **Galeria de projetos** com descrição e links
- 🛠️ **Habilidades e tecnologias** que venho estudando
- 📬 **Contato** com links para redes profissionais
- ⚡ **Carregamento rápido** e publicação contínua na Vercel

## 🚀 Como executar localmente

### Pré-requisitos

- [Git](https://git-scm.com/) instalado

### Passo a passo

```bash
# 1. Clone o repositório
git clone https://github.com/jjoaohartmann/portfoliohartmann.git

# 2. Acesse a pasta do projeto
cd portfoliohartmann

# 3. Abra o projeto no navegador
# Basta abrir o arquivo index.html
# ou usar a extensão Live Server do VS Code
```
